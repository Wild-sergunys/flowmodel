# Форматы запросов и ошибок flowmodel API

## Общий формат запросов

Все запросы с телом принимают JSON. Заголовок Content-Type: application/json обязателен.

## Общий формат успешного ответа

Для операций создания возвращается ID:
{
  "id": 5
}

Для операций обновления/удаления возвращается сообщение:
{
  "message": "Операция выполнена успешно"
}

## Формат ошибки

Все ошибки возвращаются в едином формате:

{
  "error": "validation_error",
  "message": "Поле 'w' должно быть больше 0.001",
  "details": {
    "field": "w",
    "value": 0,
    "constraint": "minimum 0.001"
  }
}

### Поля ответа с ошибкой

| Поле | Тип | Описание |
|------|-----|----------|
| error | string | Тип ошибки (код) |
| message | string | Человекочитаемое сообщение |
| details | object | Дополнительная информация (опционально) |

### Типы ошибок

| Код | HTTP | Описание |
|-----|------|----------|
| validation_error | 400 | Ошибка валидации входных данных |
| invalid_credentials | 401 | Неверный логин или пароль |
| unauthorized | 401 | Не авторизован |
| forbidden | 403 | Нет прав доступа |
| not_found | 404 | Ресурс не найден |
| conflict | 400 | Конфликт данных (например, логин уже занят) |
| internal_error | 500 | Внутренняя ошибка сервера |

## HTTP-коды ответов

| Код | Название | Когда используется |
|-----|----------|---------------------|
| 200 | OK | Успешный GET, PUT, DELETE |
| 201 | Created | Успешный POST (ресурс создан) |
| 400 | Bad Request | Ошибка валидации, конфликт данных |
| 401 | Unauthorized | Не авторизован (нет сессии) |
| 403 | Forbidden | Авторизован, но нет прав |
| 404 | Not Found | Ресурс не найден |
| 500 | Internal Server Error | Ошибка сервера |

## Примеры

### Успешный логин (200)
{
  "role": "admin",
  "message": "Вход выполнен успешно"
}

### Ошибка логина (401)
{
  "error": "invalid_credentials",
  "message": "Неверный логин или пароль"
}

### Успешный расчёт (200)
{
  "productivity": 0.001875,
  "temperature": 158.7,
  "viscosity": 6200.5,
  "profile": [
    {"x": 0, "temperature": 145.0, "viscosity": 12000.0}
  ],
  "metrics": {
    "calc_time_ms": 42,
    "memory_used_bytes": 2048000
  }
}

### Ошибка валидации расчёта (400)
{
  "error": "validation_error",
  "message": "Неверные входные параметры",
  "details": {
    "fields": [
      {"field": "w", "error": "должно быть больше 0.001"},
      {"field": "steps", "error": "должно быть не менее 10"}
    ]
  }
}

### Создание материала (201)
{
  "id": 2
}

### Материал не найден (404)
{
  "error": "not_found",
  "message": "Материал с id=999 не найден"
}

### Конфликт при создании пользователя (400)
{
  "error": "conflict",
  "message": "Пользователь с логином 'admin' уже существует"
}

### Удаление последнего админа (400)
{
  "error": "forbidden",
  "message": "Нельзя удалить последнего администратора системы"
}
