# Состав отчёта о моделировании flowmodel

## Обзор

Отчёт формируется после выполнения расчёта и содержит:
1. Входные параметры моделирования
2. Параметры выбранного материала
3. Результаты расчёта (итоговые показатели)
4. Таблицу распределений температуры и вязкости
5. Метрики производительности расчёта

Отчёт доступен в двух форматах:
- JSON через эндпоинт /api/results/{id}/report
- Excel (.xlsx) через эндпоинт /api/results/{id}/download
