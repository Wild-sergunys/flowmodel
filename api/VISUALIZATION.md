# Данные для визуализации flowmodel

## Обзор

Для визуализации результатов моделирования бэкенд возвращает:
1. Профили распределения температуры и вязкости по длине канала (для 2D/3D графиков)
2. Итоговые показатели процесса (производительность, температура продукта, вязкость продукта)
3. Метрики производительности расчёта

## Структура ответа эндпоинта /api/calculate

{
  "productivity": 0.001875,
  "temperature": 158.7,
  "viscosity": 6200.5,
  "profile": [
    {"x": 0.0, "temperature": 145.0, "viscosity": 12000.0},
    {"x": 0.095, "temperature": 145.8, "viscosity": 11850.3},
    ...
    {"x": 9.5, "temperature": 158.7, "viscosity": 6200.5}
  ],
  "metrics": {
    "calc_time_ms": 42,
    "memory_used_bytes": 2048000
  }
}

## Описание полей

### Корневые поля (итоговые показатели)

| Поле | Тип | Ед. изм. | Описание | Где отображать |
|------|-----|----------|----------|-----------------|
| productivity | number | м³/с | Объёмный расход (производительность) | Карточка "Производительность" |
| temperature | number | °С | Температура продукта на выходе | Карточка "Температура на выходе" |
| viscosity | number | Па·с | Вязкость продукта на выходе | Карточка "Вязкость на выходе" |

### profile (массив точек)

| Поле | Тип | Ед. изм. | Описание |
|------|-----|----------|----------|
| x | number | м | Координата по длине канала |
| temperature | number | °С | Средняя температура в сечении |
| viscosity | number | Па·с | Динамическая вязкость в сечении |

### metrics (показатели экономичности)

| Поле | Тип | Ед. изм. | Описание |
|------|-----|----------|----------|
| calc_time_ms | integer | мс | Время выполнения расчёта |
| memory_used_bytes | integer | байт | Объём использованной памяти |

## Визуализация

### 2D графики

Из массива `profile` строятся два графика:
1. **T(x)** — зависимость температуры от координаты
   - Ось X: `x` (м)
   - Ось Y: `temperature` (°С)

2. **η(x)** — зависимость вязкости от координаты
   - Ось X: `x` (м)
   - Ось Y: `viscosity` (Па·с)

### 3D графики (сравнение вариантов)

При варьировании параметров (Vu, Tu) для каждого варианта получается свой `profile`.
Для построения 3D-поверхности:
- Ось X: координата `x` (м)
- Ось Y: номер варианта или значение варьируемого параметра
- Ось Z: `temperature` или `viscosity`

### Табличный вывод

Массив `profile` выводится в виде таблицы:
| X, м | T, °С | η, Па·с |
|------|-------|---------|
| 0.0 | 145.0 | 12000.0 |
| 0.095 | 145.8 | 11850.3 |
| ... | ... | ... |

## Пример для ПВХ (из ТЗ)

Параметры расчёта:
- W = 0.25 м
- H = 0.01 м
- L = 9.5 м
- Vu = 1.5 м/с
- Tu = 150 °С
- T0 = 145 °С
- steps = 100

Ожидаемая структура ответа:

{
  "productivity": 0.001875,
  "temperature": 152.3,
  "viscosity": 8450.2,
  "profile": [
    {"x": 0.0, "temperature": 145.0, "viscosity": 12000.0},
    {"x": 9.5, "temperature": 152.3, "viscosity": 8450.2}
  ],
  "metrics": {
    "calc_time_ms": 15,
    "memory_used_bytes": 2048
  }
}

## Примечания

- Количество точек в `profile` соответствует параметру `steps` из запроса
- Точки распределены равномерно по длине канала: dx = L / steps
- Первая точка соответствует x = 0 (вход в канал)
- Последняя точка соответствует x = L (выход из канала)
- Значения в `metrics` вычисляются бэкендом в процессе расчёта
