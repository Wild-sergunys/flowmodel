# Данные для визуализации flowmodel

## Обзор

Для визуализации результатов моделирования бэкенд возвращает:
1. Профили распределения температуры и вязкости по длине канала (для 2D/3D графиков)
2. Итоговые показатели процесса (производительность, температура продукта, вязкость продукта)
3. Метрики производительности расчёта
4. Идентификатор сохранённого расчёта

## Структура ответа эндпоинта /api/calculate

{
  "id": 42,
  "productivity": 9081.01,
  "temperature": 170.0,
  "viscosity": 784.8,
  "profile": [
    {"x": 0.0, "temperature": 145.0, "viscosity": 8526.1},
    {"x": 0.19, "temperature": 145.5, "viscosity": 8106.3},
    ...
    {"x": 9.5, "temperature": 170.0, "viscosity": 784.8}
  ],
  "metrics": {
    "calc_time_ms": 2,
    "memory_used_bytes": 5000
  }
}

## Структура ответа эндпоинта /api/calculate/surface

{
  "points": [
    {"vu": 0.75, "tu": 130, "viscosity": 12450.3, "productivity": 6251.4},
    {"vu": 0.75, "tu": 131.7, "viscosity": 12120.1, "productivity": 6251.4}
  ]
}

## Описание полей

### Корневые поля (итоговые показатели)

| Поле | Тип | Ед. изм. | Описание | Где отображать |
|------|-----|----------|----------|-----------------|
| id | integer | - | Идентификатор сохранённого расчёта | Для истории и скачивания отчёта |
| productivity | number | кг/ч | Массовый расход (производительность) | Карточка "Производительность" |
| temperature | number | °C | Температура продукта на выходе | Карточка "Температура на выходе" |
| viscosity | number | Па·с | Вязкость продукта на выходе | Карточка "Вязкость на выходе" |

### profile (массив точек)

| Поле | Тип | Ед. изм. | Описание |
|------|-----|----------|----------|
| x | number | м | Координата по длине канала |
| temperature | number | °C | Средняя температура в сечении |
| viscosity | number | Па·с | Динамическая вязкость в сечении |

### metrics (показатели экономичности)

| Поле | Тип | Ед. изм. | Описание |
|------|-----|----------|----------|
| calc_time_ms | integer | мс | Реальное время выполнения расчёта (измеряется через time.Since) |
| memory_used_bytes | integer | байт | Реальный объём использованной памяти (измеряется через runtime.MemStats) |

### points (3D поверхность)

| Поле | Тип | Ед. изм. | Описание |
|------|-----|----------|----------|
| vu | number | м/с | Скорость крышки |
| tu | number | °C | Температура крышки |
| viscosity | number | Па·с | Вязкость продукта на выходе |
| productivity | number | кг/ч | Производительность |

## Визуализация

### 2D график

Из массива profile строится совмещённый график с двумя осями Y:
1. Кривая температуры T(x):
   - Ось X: координата x (м)
   - Ось Y (левая): temperature (°C)
   - Цвет: розовый (#ff3c8e)

2. Кривая вязкости n(x):
   - Ось X: координата x (м)
   - Ось Y (правая): viscosity (Па·с)
   - Цвет: жёлто-зелёный (#c8ff00)

### 3D график

Строится поверхность вязкости в зависимости от Vu и Tu:
- **Ось X**: скорость крышки Vu (м/с)
- **Ось Y**: вязкость продукта (Па·с) — высота поверхности
- **Ось Z**: температура крышки Tu (°C)

Диапазоны осей:
- Vu: от 0.5 * Vu до 1.5 * Vu
- Tu: от Tu - 20 до Tu + 20
- Вязкость: вычисляется для каждой пары (Vu, Tu)

На поверхности отображается точка текущего режима (чёрный маркер).

### Табличный вывод

Массив profile выводится в виде таблицы:
| X, м | T, °C | η, Па·с |
|------|-------|---------|
| 0.0000 | 145.0 | 8526.1 |
| 0.1900 | 145.5 | 8106.3 |
| ... | ... | ... |

## Пример для ПВХ

Параметры расчёта:
- W = 0.25 м
- H = 0.01 м
- L = 9.5 м
- Vu = 1.5 м/с
- Tu = 150 °C
- steps = 50

Ожидаемая структура ответа:

{
  "id": 1,
  "productivity": 9081.01,
  "temperature": 170.0,
  "viscosity": 784.8,
  "profile": [
    {"x": 0.0, "temperature": 145.0, "viscosity": 8526.1},
    {"x": 9.5, "temperature": 170.0, "viscosity": 784.8}
  ],
  "metrics": {
    "calc_time_ms": 2,
    "memory_used_bytes": 5000
  }
}

## Примечания

- Количество точек в profile равно steps + 1
- Точки распределены равномерно по длине канала: dx = L / steps
- Первая точка: x = 0, температура = температура плавления материала
- Последняя точка: x = L, температура и вязкость на выходе из канала
- Метрики calc_time_ms и memory_used_bytes измеряются реально, а не вычисляются приблизительно
- Для 3D поверхности используется параллельный пул воркеров (worker pool) для ускорения расчётов
