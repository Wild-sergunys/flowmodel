# Данные для визуализации flowmodel

## Обзор

Для визуализации результатов моделирования бэкенд возвращает:
1. Профили распределения температуры и вязкости по длине канала (для 2D/3D графиков)
2. Итоговые показатели процесса (производительность, температура продукта, вязкость продукта)
3. Метрики производительности расчёта
4. Идентификатор сохранённого расчёта

## Структура ответа эндпоинта /api/calculate

{
  "id": 42,
  "productivity": 248.63,
  "temperature": 158.7,
  "viscosity": 6200.5,
  "profile": [
    {"x": 0.0, "temperature": 145.0, "viscosity": 12000.0},
    {"x": 0.095, "temperature": 145.8, "viscosity": 11850.3},
    ...
    {"x": 9.5, "temperature": 158.7, "viscosity": 6200.5}
  ],
  "metrics": {
    "calc_time_ms": 42,
    "memory_used_bytes": 2048000
  }
}

## Описание полей

### Корневые поля (итоговые показатели)

| Поле | Тип | Ед. изм. | Описание | Где отображать |
|------|-----|----------|----------|-----------------|
| id | integer | - | Идентификатор сохранённого расчёта | Для истории и скачивания отчёта |
| productivity | number | кг/ч | Массовый расход (производительность) | Карточка "Производительность" |
| temperature | number | °C | Температура продукта на выходе | Карточка "Температура на выходе" |
| viscosity | number | Па·с | Вязкость продукта на выходе | Карточка "Вязкость на выходе" |

### profile (массив точек)

| Поле | Тип | Ед. изм. | Описание |
|------|-----|----------|----------|
| x | number | м | Координата по длине канала |
| temperature | number | °C | Средняя температура в сечении |
| viscosity | number | Па·с | Динамическая вязкость в сечении |

### metrics (показатели экономичности)

| Поле | Тип | Ед. изм. | Описание |
|------|-----|----------|----------|
| calc_time_ms | integer | мс | Время выполнения расчёта |
| memory_used_bytes | integer | байт | Объём использованной памяти |

## Визуализация

### 2D график

Из массива profile строится совмещённый график с двумя осями Y:
1. Кривая температуры T(x):
   - Ось X: координата x (м)
   - Ось Y (левая): temperature (°C)
   - Цвет: розовый (#ff3c8e)

2. Кривая вязкости n(x):
   - Ось X: координата x (м)
   - Ось Y (правая): viscosity (Па·с)
   - Цвет: жёлто-зелёный (#c8ff00)

### 3D график

Строится поверхность производительности в зависимости от Vu и Tu:
- Ось X: скорость крышки Vu (м/с)
- Ось Y: температура крышки Tu (°C)
- Ось Z: производительность Q (м³/с)

Диапазоны осей:
- Vu: от 0.5 * Vu до 1.5 * Vu (но не менее 0.0001)
- Tu: от min(температура профиля, Tu) до max(температура профиля, Tu)
- Q: вычисляется для каждой пары (Vu, Tu) через интерполяцию вязкости по температуре

На поверхности отображается точка текущего режима (маркер).

### Табличный вывод

Массив profile выводится в виде таблицы:
| X, м | T, °C | n, Па·с |
|------|-------|---------|
| 0.0000 | 145.0 | 12000.0 |
| 0.0950 | 145.8 | 11850.3 |
| ... | ... | ... |

## Пример для ПВХ

Параметры расчёта:
- W = 0.25 м
- H = 0.01 м
- L = 9.5 м
- Vu = 1.5 м/с
- Tu = 150 °C
- T0 = 145 °C
- steps = 100

Ожидаемая структура ответа:

{
  "id": 1,
  "productivity": 248.63,
  "temperature": 152.3,
  "viscosity": 8450.2,
  "profile": [
    {"x": 0.0, "temperature": 145.0, "viscosity": 12000.0},
    {"x": 9.5, "temperature": 152.3, "viscosity": 8450.2}
  ],
  "metrics": {
    "calc_time_ms": 15,
    "memory_used_bytes": 2048
  }
}

## Примечания

- Количество точек в profile равно steps + 1 (от 0 до steps включительно)
- Точки распределены равномерно по длине канала: dx = L / steps
- Первая точка: x = 0, температура = начальная температура материала (melting_temp)
- Последняя точка: x = L, температура и вязкость на выходе из канала
- Значения в metrics вычисляются бэкендом в процессе расчёта: calc_time_ms = steps * 2, memory_used_bytes = steps * 4096
